Phase 0 publishes a fail-closed runtime contract only.

The native editor remains disabled until the upstream web application can meet the required offline and sandbox policy.

  • Unique-origin isolation is required.
  • No network access is allowed.
  • No wildcard, inline, or eval-based execution is allowed.

Compatibility evidence and the gating decision are recorded in the repository documentation and are not served from this runtime endpoint.
